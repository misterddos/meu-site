# Lippy Workspace

Área de trabalho pessoal, versão inicial.

## Executar no Termux

Na pasta do projeto:

    python -m http.server 8080 --bind 0.0.0.0

Abra no navegador:

    http://127.0.0.1:8080

## Recursos desta versão

- Interface responsiva com tema escuro.
- Player de áudio local usando arquivos selecionados pelo usuário.
- Link para o canal do MBL no YouTube.
- Link para o Instagram.
- Avisos iniciais de uso e privacidade.

O player não envia músicas para um servidor. A autenticação GitHub ainda não foi implementada.
